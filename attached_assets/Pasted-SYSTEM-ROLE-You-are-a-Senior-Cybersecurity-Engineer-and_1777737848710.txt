BACKEND SPEC — IMPLEMENT EXACTLY AS DESCRIBED
═══════════════════════════════════════════════════════════

── sniffer.py ──────────────────────────────────────────
Use Scapy's AsyncSniffer on interface "lo" (fallback: "eth0").
Capture filter: "ip". Store last 500 packets in a thread-safe
collections.deque(maxlen=500). Expose a get_packets() function
that returns the deque as a list.

── parser.py ────────────────────────────────────────────
For each Scapy packet, extract:
  - timestamp (ISO 8601)
  - src_ip, dst_ip, src_port, dst_port
  - protocol ("TCP" | "UDP" | "ICMP" | "OTHER")
  - length (bytes)
  - flags (TCP flags as string, e.g. "SYN", "ACK", "SYN-ACK")
  - ttl
Return as a dict matching the PacketRecord Pydantic schema.

── anomaly.py ───────────────────────────────────────────
Sliding window of last 60 seconds of packet lengths.
Compute: mean, std_dev, z_score for each new packet.
Flag as anomaly if abs(z_score) > 2.5 OR if packet rate
(packets/sec) exceeds 3× the rolling 60s average.
Also flag: identical src→dst pairs appearing >20x in 10s
(connection flood indicator).
Return: AnomalyResult(is_anomaly: bool, z_score: float,
reason: str, severity: "LOW"|"MED"|"HIGH"|"CRITICAL")

── port_scanner.py ──────────────────────────────────────
Use python-nmap (nmap.PortScanner). On a detected new external IP,
run a non-intrusive scan: nm.scan(ip, arguments="-sV -T2 --top-ports 100").
Parse open ports. Compute port_scan_score:
  score = (open_ports_count * 3) + (sensitive_ports_hit * 10)
  sensitive_ports = [22, 23, 3389, 445, 1433, 3306, 6379, 27017]
Return: PortScanResult(ip, open_ports[], sensitive_ports[], score)

── compliance.py ─────────────────────────────────────────
Rule engine. Each rule is a dict: {id, framework, description,
triggered: bool, evidence: str}

Implement these rules:
  PCI-DSS-1.2: Flag unencrypted traffic on port 80 to/from
               RFC1918 addresses → "Clear-text data in CDE"
  PCI-DSS-6.5: Flag any packet with dst_port=23 (Telnet) →
               "Insecure protocol in use"
  NIST-SI-3:   Flag if anomaly rate >5% of total traffic →
               "Malicious code event threshold exceeded"
  NIST-AC-17:  Flag dst_port=3389 (RDP) from non-RFC1918 src →
               "Remote access from untrusted network"

── resolver.py ───────────────────────────────────────────
Use geoip2 (MaxMind GeoLite2-City.mmdb — include download
instruction in README). For each unique external IP:
  - Return: GeoResult(ip, latitude, longitude, country,
    city, asn, org)
Cache results in a dict. Skip RFC1918 addresses.

── routes_packets.py ─────────────────────────────────────
GET  /api/packets          → last 100 parsed packets (JSON)
GET  /api/packets/stream   → SSE endpoint, push new packets
                             every 500ms using asyncio + yield

── routes_threats.py ─────────────────────────────────────
GET  /api/threats          → list of AnomalyResults
GET  /api/threat-level     → ThreatLevel(score: int 0-100,
     label: "NORMAL"|"ELEVATED"|"HIGH"|"CRITICAL",
     top_threats: str[])
     Score formula: (anomaly_ratio*40) + (max_port_score/10) +
     (active_compliance_flags*15), clamped to 100.

── routes_compliance.py ──────────────────────────────────
GET  /api/compliance/report → full ComplianceReport(
     timestamp, total_packets_analyzed, rules_triggered[],
     risk_rating: "PASS"|"WARN"|"FAIL")

── schemas.py ────────────────────────────────────────────
Define Pydantic v2 BaseModel classes for:
PacketRecord, AnomalyResult, PortScanResult, GeoResult,
ThreatLevel, ComplianceRule, ComplianceReport
