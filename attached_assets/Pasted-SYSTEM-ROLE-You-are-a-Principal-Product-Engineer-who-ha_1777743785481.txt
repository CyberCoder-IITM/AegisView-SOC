FEATURE 2 — SESSION REPLAY & TIMELINE SCRUBBER
═══════════════════════════════════════════════════════════════════

One of the most requested features in real SOC tools.
"What happened 8 minutes ago?" — AegisView can now answer.

Create backend/analysis/session_recorder.py:

  Class SessionRecorder:
    Records snapshots every 10 seconds:
    
    Snapshot(
      timestamp: ISO8601,
      snapshot_id: str,        (uuid)
      threat_level: int,
      anomaly_count: int,
      active_compliance_flags: int,
      kill_chain_stages: list[str],   (active stage names)
      top_src_ips: list[str],         (top 5 by packet count)
      packets_per_second: float,
      baseline_mode: str,
      agent_latest_attribution: str | null,
      packet_sample: list[dict]        (10 representative packets)
    )
    
    Store: deque(maxlen=360)  (360 × 10s = 60 minutes of history)
    
    Routes:
      GET /api/replay/snapshots → list of all snapshots
        (return only: snapshot_id, timestamp, threat_level, 
         anomaly_count — lightweight index for scrubber)
      GET /api/replay/snapshot/{snapshot_id} → full snapshot
      GET /api/replay/timeline → threat_level over time array:
        [{timestamp, threat_level, anomaly_count, 
          had_critical: bool}]

FEATURE 5 — NATURAL LANGUAGE QUERY ENGINE
═══════════════════════════════════════════════════════════════════

Type a question in plain English. AegisView answers using 
your actual live packet data. This is what Microsoft Copilot 
for Security charges $4/user/hour for.

Create backend/api/routes_query.py:

  POST /api/query:
    Body: { question: str }
    
    Process:
      1. Gather current context:
         - Last 50 packets summary
         - Current threat level
         - Active compliance flags
         - Kill chain status
         - Device profiles summary
         - Baseline status
         - Recent agent cycles
      
      2. Send to Gemini with this system prompt:
         "You are AegisView's query engine. You have access to 
          real-time network data provided below. Answer the 
          analyst's question using ONLY this data. Be specific,
          reference actual IPs, ports, timestamps from the data.
          If the answer is not in the data, say exactly:
          'This information is not available in the current 
          capture window.'
          
          Format: 2-4 sentences max. No markdown. Plain text.
          Never invent data not present in the context."
         
         Append full context JSON to prompt.
      
      3. Return: {
           answer: str,
           data_points_used: int,    (count of packets in context)
           confidence: "HIGH"|"MED"|"LOW",
           timestamp: ISO8601
         }
    
    Example questions that must work:
      "Which IP is sending the most traffic right now?"
      "Are there any Telnet connections in the last 5 minutes?"
      "What is the current compliance status?"
      "Which device has changed behavior the most?"
      "Is there any sign of data exfiltration?"
